# Breach

## Metadata
- **Patch Version:** 3.25
- **Scaling Tags:** ["quantity", "pack_size", "breach_density"]
- **Is Scarab Heavy:** true

## Overview
Breach encounters open a timed portal that expands as you kill monsters. Splinters drop from Breach monsters and combine into Breachstones, which open a Breach Lord domain. Breachstones can be upgraded and enriched for higher-tier loot. Breach is excellent for raw splinter farming at scale.

## How to Run
1. Allocate Atlas passives for Breach (additional Breaches, splinter quantity)
2. Use Breach Scarabs for guaranteed extra Breaches per map
3. Run high-density T16 maps to maximize splinter drops per breach
4. Sell Breachstones in bulk — Chayula and Uul-Netol are most valuable
5. Consider upgrading Breachstones via Betrayal's It That Fled bench for profit
