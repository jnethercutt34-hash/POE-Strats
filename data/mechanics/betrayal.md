# Betrayal

## Metadata
- **Patch Version:** 3.25
- **Scaling Tags:** ["syndicate_intel", "safehouse_rank", "map_tier"]
- **Is Scarab Heavy:** true

## Overview
Betrayal involves manipulating the Immortal Syndicate board to place high-value members into specific Safehouse divisions. Each Safehouse (Transportation, Fortification, Research, Intervention) has a leader whose rank determines reward quality. The Mastermind fight is the ultimate boss. Key outputs are Scarabs, Veiled items, bench crafts (e.g., It That Fled's Breachstone upgrade), and Pure Breachstones.

## How to Run
1. Allocate Atlas passives for Betrayal (Syndicate intel, Safehouse quality)
2. Use Betrayal Scarabs for extra Syndicate encounters
3. Manipulate the board: It That Fled → Research, Cameria → Intervention
4. Run Safehouses when leaders reach Rank 3 for max rewards
5. Sell Scarabs in bulk from Intervention Safehouse
