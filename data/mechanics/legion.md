## Overview
Legion encounters freeze two opposing armies in time. Breaking enemies out before the timer ends releases them for loot. Rewards include Splinters (for Emblems), Incubators, and general drops scaled by how many enemies you free. Clear speed is king — the more you break, the more you earn.

## How to Run
1. Allocate Atlas passives for Legion (war hoard, additional armies)
2. Use Legion Scarabs for guaranteed encounters
3. Build for AoE clear — you need to break as many monsters as possible in ~12 seconds
4. Target Maraketh and Templar generals for highest-value splinters
5. Run 5-way Emblems for massive returns (requires party or strong build)
