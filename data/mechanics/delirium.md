# Delirium

## Metadata
- **Patch Version:** 3.25
- **Scaling Tags:** ["quantity", "clear_speed", "delirium_orbs"]
- **Is Scarab Heavy:** true

## Overview
Delirium encounters spawn a fog that increases monster density and reward tiers the further you push. Rewards come from Simulacrum Splinters (30 = 1 Simulacrum), Delirium Orbs (applied to maps for permanent delirium), and Cluster Jewels. Simulacrum runs are a major endgame currency farm.

## How to Run
1. Allocate Atlas passives for Delirium (reward tiers, persistent fog)
2. Use Delirium Scarabs for guaranteed encounters
3. Speed is critical — push as deep into the fog as possible before it dissipates
4. Collect Simulacrum Splinters → run Simulacrums for massive profits
5. Delirium Orbs applied to T16 maps create "100% delirious" maps for group content
