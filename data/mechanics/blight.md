# Blight

## Metadata
- **Patch Version:** 3.25
- **Scaling Tags:** ["tower_damage", "anointments", "map_tier"]
- **Is Scarab Heavy:** true

## Overview
Blight encounters are tower defense events where you place towers along fungal paths to protect the pump. Rewards come from chests at the end — Blighted Maps, Oils (for anointments), and occasional high-value unique drops. Blight-Ravaged Maps are the premium endgame content.

## How to Run
1. Allocate Atlas passives for Blight (additional lanes, chest quality)
2. Use Blight Scarabs for guaranteed encounters
3. Build towers strategically: Empowering → Meteor/Temporal on choke points
4. Sell Oils in bulk — Golden Oil, Silver Oil, Teal Oil are consistently valuable
5. Run Blighted Maps for concentrated loot (requires tower defense focus)
