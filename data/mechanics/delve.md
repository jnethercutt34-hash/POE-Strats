# Delve

## Metadata
- **Patch Version:** 3.25
- **Scaling Tags:** ["depth", "quantity", "sulphite"]
- **Is Scarab Heavy:** true

## Overview
Delve is an infinite dungeon-crawling mechanic accessed via the Azurite Mine. Players spend Sulphite to explore deeper, with monster level and reward scaling with depth. The Voltaxic Sulphite Generator upgrades are key to maximizing returns.

## How to Run
1. Use Gilded/Polished Sulphite Scarabs to generate Sulphite in maps
2. Prioritize Voltaxic Generator upgrades: Sulphite capacity → Darkness resistance → Light radius
3. Target depth 200-400 for optimal profit/time ratio
4. Focus on Fossil nodes and Currency nodes at depth
5. Side areas (Vaal Outposts, Abyssal Cities) can contain high-value uniques
