# Harvest

## Metadata
- **Patch Version:** 3.25
- **Scaling Tags:** ["quantity", "pack_size", "map_tier"]
- **Is Scarab Heavy:** true

## Overview
Harvest encounters spawn in maps, offering crafting options and sellable Lifeforce currency. The three Lifeforce types (Vivid/Wild/Primal) are the primary tradeable output. Atlas passives and Harvest Scarabs significantly increase yields.

## How to Run
1. Allocate Atlas passives for Harvest (Sacred Grove nodes)
2. Use Harvest Scarabs to guarantee/enhance encounters
3. Run T16 maps for maximum monster level and Lifeforce drops
4. Sell Lifeforce in bulk — Vivid (yellow) is typically most valuable
5. High-value crafts (Reforge Keep Prefix/Suffix) can be sold as services for extra profit
